### 3. 修复商品详情页黑屏崩溃问题

**文件**: `src/views/TradeItemDetail.vue`

修复 **7 处崩溃点**：

| 问题 | 修复 |
|------|------|
| `reactive` 未导入导致组件初始化崩溃 | 补充 `import { reactive }` |
| `item.seller.avatar/username/id` 为 null | 整个卖家卡片加 `v-if="item.seller"` |
| `item.price / item.originalPrice` 为 null → NaN | 加 `v-if` 条件 + `?? 0` 兜底 |
| `item.images[0]` 为 null | `v-if="currentImage"` + 占位符 |
| `handleBuy` 中 `seller.id` 为 null | 前置检查 + 提示 |
| 后端 Jackson `@class` 序列化导致 `price/images` 格式异常 | `api.js` 新增 `normalizeTradeItem` 数据清洗函数 |
| 「我想要」按钮被 `v-if="!isOwner"` 隐藏 | 移除条件，始终显示下单按钮 |
